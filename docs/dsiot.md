# MCK706A の dsiot API

MCK706A が LAN に公開している API (dsiot) の仕組みと、このサーバーが使うプロパティの対応表です。
`/api/tree`・`/api/read`・`/api/write` で本体を直接調べたり書き換えたりするときと、新しいプロパティを公開するときに使います。

内容は、公式アプリ (DAIKIN Smart APP) の空気清浄機向けの定義 (`GPFCjConvertValue` の enum 表と `strings.xml` のラベル) と、実機 (MCK706A、ファームウェア `3_15_0`、`api_ver 2_2`) での読み書きで確かめたものです。

## リクエストとレスポンス

本体の API は次の 1 つの endpoint だけで、認証はありません。古いダイキン機の `/cleaner/*`・`/common/*` は持ちません。

```
POST http://<host>/dsiot/multireq
```

本文の `requests` 配列の各要素は、操作コード `op` と対象のアドレス `to` を持ちます。

| `op` | 操作     | 要素に足すもの                   |
| ---- | -------- | -------------------------------- |
| `2`  | 読み取り | —                                |
| `3`  | 書き込み | `pc`: 書き込むプロパティのツリー |

レスポンスの `responses` 配列の各要素は、次のフィールドを持ちます。

| フィールド | 意味                                                      |
| ---------- | --------------------------------------------------------- |
| `fr`       | 応答元のアドレス                                          |
| `rsc`      | 結果コード (JSON の整数)                                  |
| `pc`       | 読み取ったプロパティのツリー (読み取りが成功したときだけ) |

| `rsc`          | 意味                                            | 根拠             |
| -------------- | ----------------------------------------------- | ---------------- |
| `2000`〜`2009` | 成功 (MCK706A は書き込みの成功に `2004` を返す) | 公式アプリの定義 |
| `4000`         | パラメータの誤り                                | 公式アプリの定義 |
| `4041`         | 存在しないアドレス                              | 実機で観測       |

ツリーの各ノードは次のフィールドを持ちます。

| フィールド        | 意味                                                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pn`              | プロパティ名 (`e_1002`、`p_01` など)                                                                                                                      |
| `pt`              | ノードの型。`1` は子 (`pch`) を持つコンテナ、`2` は設定値のリーフ、`3` はセンサー値と固定の情報のリーフ (実機で観測)。書き込むリーフは `3` でも受け付ける |
| `pv`              | 値 (リーフだけ)                                                                                                                                           |
| `md.pt`           | 値の符号化。`b` はリトルエンディアンの 16 進バイト列、`i` は整数、`s` は文字列                                                                            |
| `md.mi` / `md.mx` | 最小値 / 最大値 (16 進)。列挙型では `md.mx` が対応する値のビットマスク (bit n が値 n)                                                                     |

本体は `md.mx` の範囲外の値も拒否せずに保存します。このサーバーの `/api/humidify`・`/api/course`・`/api/fan-speed`・`/api/humidity-setting` は `md.mx` で範囲を確かめてから書き込みますが、`/api/power` (値は `00` / `01` だけ) と `/api/write` は確かめません。

`/api/write` の本文は次のとおりです。例は電源を切ります。

| フィールド    | 値                                                |
| ------------- | ------------------------------------------------- |
| `to`          | 書き込むコンテナのアドレス                        |
| `entity_path` | `to` のコンテナから下のプロパティ名の並び         |
| `pv`          | リトルエンディアンの 16 進文字列 (空でない偶数長) |
| `confirm`     | JSON の `true`                                    |

```sh
curl -X POST http://127.0.0.1:8000/api/write \
  -H 'Content-Type: application/json' \
  -d '{"to":"/dsiot/edge/adr_0100.dgc_status","entity_path":["e_1002","e_A002","p_01"],"pv":"00","confirm":true}'
```

## アドレス

`/api/read` で `/dsiot/edge` を読むと、本体が持つアドレスがすべて返ります。

```sh
curl -X POST http://127.0.0.1:8000/api/read \
  -H 'Content-Type: application/json' \
  -d '{"targets":["/dsiot/edge"]}'
```

| アドレス                                            | 内容                                                                         | 使う endpoint                               |
| --------------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------- |
| `/dsiot/edge/adr_0100.dgc_status`                   | 運転の制御とセンサー                                                         | `/api/status`・`/api/tree`・操作の endpoint |
| `/dsiot/edge.adp_i`                                 | アダプタの情報 (ファームウェア・MAC・自身の AP の SSID・api_ver・機能フラグ) | `/api/info`                                 |
| `/dsiot/edge.adp_d`                                 | ユーザー設定 (名前・LED・タイムゾーン・自動 OFF の通知)                      | `/api/info`                                 |
| `/dsiot/edge.adp_r`                                 | 無線の接続状態 (接続中の SSID・RSSI) と、再起動・ファームウェア更新の履歴    | `/api/info`                                 |
| `/dsiot/edge.dev_i`                                 | 機器の種別 (`type` が `1D` なら空気清浄機) と接続台数                        | `/api/info`                                 |
| `/dsiot/edge.adp_f`                                 | ファームウェアの種別と自動更新の有効 / 無効                                  | `/api/read` だけ                            |
| `/dsiot/edge/adr_0100.scdl_t.info` / `.scdl_t.body` | 週間スケジュールタイマー (値は JSON)                                         | `/api/read` だけ                            |
| `/dsiot/edge/adr_0200.dgc_status`                   | 空 (エアコンの室外機用のアドレス)                                            | —                                           |
| `/dsiot/edge/adr_0100.history`                      | アプリの空気質の履歴。MCK706A では `4041` で読めない                         | —                                           |
| `/dsiot/edge/adr_0100.i_power.*`                    | 消費電力。MCK706A では `4041` で読めない                                     | —                                           |

## プロパティ対応表

`/api/status` のフィールドと、`dgc_status` の下のプロパティの対応です。値の列は `pv` の値とその意味です。

| フィールド                                 | プロパティ                                                   | 値                                                                                                    | 根拠                                         |
| ------------------------------------------ | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `power`                                    | `e_1002/e_A002/p_01`                                         | `00` / `01`                                                                                           | 実機で書き込み                               |
| `humidify`                                 | `e_1002/e_3001/p_3F`                                         | `00` 空気清浄、`01` 除湿 + 空気清浄 (MCK706A 非対応)、`02` 加湿 + 空気清浄                            | 実機で書き込み                               |
| `course`                                   | `e_1002/e_3007/p_01` (空気清浄側) / `p_03` (加湿側)          | 2 バイト LE。下位バイトがコード (`00` smart … `06` circulator … `0A` internal_dry)、上位バイトは `00` | 実機で書き込み                               |
| `fan_speed`                                | `e_1002/e_3007/p_04` (空気清浄側) / `p_06` (加湿側)          | `00` quiet … `04` turbo                                                                               | 実機で書き込み                               |
| `humidity_setting`                         | `e_1002/e_3007/p_12`〜`p_1C` (加湿側。コードの順に 1 つずつ) | `00` off、`01` low、`02` standard、`03` high、`04` continuous                                         | 実機で書き込み (`p_13`)                      |
| `temperature_c`                            | `e_1002/e_A00B/p_01`                                         | int16 LE、0.5 ℃ 単位 (`md.st` が `0xF5`)                                                              | 実機                                         |
| `humidity_pct`                             | `e_1002/e_A00B/p_02`                                         | %                                                                                                     | 実機                                         |
| `pm25_level` / `dust_level` / `odor_level` | `e_1002/e_3007/p_1D` / `p_1E` / `p_1F`                       | 0〜5                                                                                                  | 公式アプリの定義 (読み取りだけ)              |
| `pm25_raw` / `dust_raw` / `odor_raw`       | `e_1002/e_3007/p_26` / `p_27` / `p_28`                       | 24 bit                                                                                                | アプリの履歴グラフの元の値と推定。単位は不明 |
| `water_supply_sign`                        | `e_1002/e_3007/p_20`                                         | flag                                                                                                  | 公式アプリの定義                             |
| `filter_drying`                            | `e_1002/e_3007/p_29`                                         | flag                                                                                                  | 公式アプリの定義                             |
| `deodorizing_filter_off_sign`              | `e_1002/e_3007/p_3E`                                         | flag                                                                                                  | 公式アプリの定義                             |
| `streamer_maintenance_sign`                | `e_1002/e_3001/p_40`                                         | flag                                                                                                  | 公式アプリの定義                             |
| `error_code`                               | `e_1002/e_A004/p_09`                                         | ASCII (`00-00` が正常)                                                                                | 公式アプリの定義                             |

本体は空気清浄側と加湿側のコース・風量を別々に持ち、MCK706A では片方を書き込むと数秒後にもう片方へ同じ値が書かれます (実機で観測)。

公式アプリの定義に無く意味の分からないプロパティ (`e_3007/p_2B`〜`p_3D` の一部、`e_205E`、`e_205F_*` など) は `/api/status` に含めていません。`/api/tree` を一定間隔で読み、本体の操作に合わせて変わる値を探すと意味を特定できます。

新しいプロパティを `/api/status` などで公開するときは、次を足します。

| ファイル               | 足すもの                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| `src/daikin/client.py` | プロパティパスの定数と、`tree.decode(パス, decoder=...)` の 1 行 (デコーダは `src/daikin/protocol.py`) |
| `src/daikin/models.py` | 応答モデルのフィールド                                                                                 |
